# Formula partner resource readiness inventory

Last source review: September 5, 2026. Event: October 14–16, 2026.

This inventory records what the website actually has. A company link is a general public link; it is not evidence that a Formula-exclusive resource, offer, booking path, representative roster, or public app page is ready. ## Required completion record

Before any partner is marked ready, record:

1. A named internal delivery owner and agreed due date.
2. The partner-supplied Formula resource title, type, URL, mobile download/view result, and post-event availability owner.
3. Any partner-supplied offer and terms. Use `NONE PROVIDED` when there is intentionally no offer.
4. A working booking/contact link. A general company homepage does not count unless the partner confirms it as the intended action.
5. The approved representative roster and public app page review result.

Never infer a resource, offer, representative, or booking destination from a company homepage. Keep `UNVERIFIED` until the Formula team receives and checks the actual deliverable.

## Keeping this true

`bun run formula:handouts:audit` re-checks every configured resource against the live
`partnerPages` mirror. It fails when a configured URL is no longer one of that org's current
handouts — which is the only way the re-upload trap surfaces, since the superseded PDF keeps
returning HTTP 200. Proven 2026-09-18: pointing an entry at a URL that returns 200
`application/pdf` but is not the org's current handout exits 1; restoring it exits 0.

Run it before any release that touches partner resources. Passing means the file still matches
the Hub. It does not mean anyone re-read the PDF — that is what this document is for.
