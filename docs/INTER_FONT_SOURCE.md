# Inter font source

The landing bundle uses `inter-latin-wght-normal.woff2` from `@fontsource-variable/inter` 5.2.6. The package records Inter v19 metadata, Google Fonts as the source, and SIL Open Font License 1.1 as the license:

`https://fontsource.org/fonts/inter`

The local CSS declares the asset as a normal variable face covering weights 100–900. The license text is retained in `docs/INTER_FONT_LICENSE.txt`.
